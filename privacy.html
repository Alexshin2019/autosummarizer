Auto Summarizer (3s) 개인정보처리방침

본 확장 프로그램은 사용자가 방문한 웹페이지의 공개 텍스트를 요약하는 기능만 제공합니다.

1. 수집하는 정보

확장 프로그램은 사용자의 개인 정보, 로그인 정보, 위치, 결제 정보 등을 수집하지 않습니다.
요약 목적을 위해 현재 페이지의 본문 텍스트만 일시적으로 OpenAI API로 전송됩니다.

2. 데이터 저장 및 보안

모든 설정 정보(OpenAI 키, 모델명, 언어 등)는 사용자의 브라우저 chrome.storage 영역에 로컬 저장되며 외부로 전송되지 않습니다.

3. 제3자 제공

어떠한 사용자 데이터도 제3자에게 판매하거나 전송하지 않습니다.

4. 데이터 삭제

사용자는 브라우저 설정에서 확장 프로그램을 삭제하면 모든 데이터가 함께 삭제됩니다.
