# Auto Summarizer (3s)

Chrome 확장 프로그램 - 페이지 입장 3초 후 자동으로 웹페이지를 요약해주는 도구입니다.

## 주요 기능

- 🚀 **자동 요약**: 페이지 로드 후 3초 후 자동으로 요약 생성
- 📝 **구조화된 요약**: 불릿 포인트와 핵심요약으로 구성
- 💡 **독특한 아이디어**: 요약 내용을 바탕으로 창의적인 아이디어 3개 제시
- 📋 **핵심요약 공유**: 핵심요약만 클릭 한 번에 복사 가능
- ⚙️ **커스터마이징**: 언어, 지연 시간, 모델 등 설정 가능

## 설치 방법

1. 이 저장소를 클론하거나 ZIP으로 다운로드
2. Chrome 브라우저에서 `chrome://extensions/` 접속
3. 우측 상단의 "개발자 모드" 활성화
4. "압축해제된 확장 프로그램을 로드합니다" 클릭
5. 이 프로젝트 폴더 선택

## 사용 방법

1. 확장 프로그램 설치 후 옵션 페이지에서 OpenAI API 키를 입력
2. 원하는 설정을 구성 (모델명, 지연 시간, 언어 등)
3. 일반 웹페이지를 방문하면 3초 후 자동으로 요약이 표시됩니다

## 파일 구조

- `manifest.json`: 확장 프로그램 설정
- `background.js`: 백그라운드 스크립트 (API 호출 처리)
- `content.js`: 콘텐츠 스크립트 (페이지 요약 실행)
- `options.html`: 설정 페이지 UI
- `options.js`: 설정 페이지 로직

## 설정 옵션

- **OpenAI API Key**: OpenAI API 키 입력
- **모델명**: 사용할 GPT 모델 (기본값: gpt-4o-mini)
- **지연 시간**: 페이지 로드 후 요약 시작까지의 시간 (기본값: 3000ms)
- **요약 최대 토큰**: 요약 생성 시 최대 토큰 수 (기본값: 800)
- **언어**: 요약 언어 선택 (한국어/영어)

## 주의사항

- OpenAI API 키가 필요합니다
- API 사용량에 따라 비용이 발생할 수 있습니다
- 일부 사이트(chrome://, accounts.google.com 등)는 자동으로 제외됩니다
